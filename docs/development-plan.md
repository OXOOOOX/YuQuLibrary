## 验证与依赖顺序

第 1–7 阶段保留 V1 的依赖与验收清单，不重复从初始化开始。当前执行顺序以下文 P0–P4 为准；真机或分发等待期间可以推进独立的本地工作，官方视频验证与音频完善并行。

优先针对验证码消费、用户隔离、播放接管、乱序事件、消息幂等和任务恢复编写有行为意义的测试。布局与交互通过浏览器和真机验证；模拟数据不能替代真实邮件、B 站下载、ASR 或 Codex 的最终验收。

暂不估算固定上线日期。真机安装通路、自然播客质量及新增能力的真实服务验收仍会影响发布范围。
