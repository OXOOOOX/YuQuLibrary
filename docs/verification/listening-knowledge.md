# 收听问答、文稿搜索与轻量收藏

日期：2026-11-18。状态：近期代码已实现并完成下述本地验证；未部署生产、未发布新 HAP。后续路线图不计为本轮已实现。

## 已实现行为

- 新问题首次输入非空内容时固定位置；快捷问题只填入、不自动发送。继续追问复用父问题原文，明确“问现在听到的”或换范围才新建话题；切回正在播放的节目保留草稿。
- 选取连续文稿句子提问／收藏；快照绑定转写任务与完成水位，续句增长不改旧选择。答案引用严格绑定当前回答，支持查看原文、问该引用、回听与收藏。
- 回听末尾暂停；本机返回点恢复原位置、倍速、循环及暂停／播放状态。其他标签或设备接管后返回点失效；HTTP 响应丢失、SSE 先到时重试仍复用同一接管意图与原返回点。
- 单集全文中文关键词搜索、英文 ASCII 大小写不敏感匹配、命中高亮和固定水位分页。按提交搜索，不只搜索前端已加载文稿。
- 文稿片段与已完成回答收藏，独立备注、本集／全部列表、回到来源。清理音频保留文字和收藏并禁用回听；整期删除在同一事务删除收藏和备注。
- 网页与鸿蒙实现资料库／收听／收藏入口，文稿／对话切换，持续播放器；独立阅读不抢占播放。
- 一个导入入口识别音频、RSS/Atom、完整 BV 编号／链接与 b23 短链接，确认预览后导入。沿用公网地址校验、固定 IP、逐跳校验及既有额度限制。

## 接口与兼容

| 接口 | 行为 |
| --- | --- |
| `POST /api/media/:id/chat` | 新请求提交 `anchor` 或 `parentTurnId`；父话题不允许并传新位置。原 `positionMs/scope` 请求保持旧语义 |
| `POST /api/media/:id/chat/check` | 检查所选范围是否已完成且未超过上下文上限；不创建话题或排队任务 |
| `GET /api/media/:id/chat?capabilities=anchored-v1` | 返回父问题、话题根及锚点；历史分页保持原 `before` 参数 |
| `GET /api/media/:id/transcript/search?q=…&cursor=…` | 返回命中片段、原文高亮位置、固定文稿快照与下一页游标 |
| `GET/POST /api/saved-items` | 分页读取／幂等保存；可按 `mediaVersionId` 筛选，原文与回答由服务端解析 |
| `PATCH/DELETE /api/saved-items/:id` | 修改自己的备注／删除收藏 |
| `POST /api/playback/takeover` | `intent=restore` 必须提交原回听代次、播放会话、目标媒体／位置及速度／循环；所有者或条件变化返回 409 |

`anchor` 支持播放位置、文稿选择、回答引用三种来源。选段最多 32 个连续片段，保留 32,000 字上下文上限。引用 S 编号仅在该回答冻结上下文内有效。新话题只使用自身祖先链最近四轮；旧位置式客户端仍使用原有逐集历史规则。

新增迁移 `0010_anchored_chat_restore.sql` 与 `0011_knowledge.sql`，不改旧迁移。集成测试文件分别重建独立测试 schema，因此测试脚本改为串行运行，防止文件之间相互重置。

**旧包边界：** 已安装旧鸿蒙包的严格响应校验不认识 `selection`。未声明能力的请求，只有实际返回页含选段问题时才返回中文 `UPGRADE_REQUIRED` 提示；纯旧记录继续可读。不会伪装范围、丢弃历史或因第 21 条预读记录阻止当前页。要查看新选段对话需新版客户端或最新版网页。

独立 CodexBridge 的鱼趣适配增加 `selection` 范围及最多 32 段校验，仍禁用工具、只依据冻结原文回答。未重启正在运行的 Bridge。

## B 站官方视频验证

直接验证[官方播放器](https://player.bilibili.com/)的示例视频，使用 `t=15`。页面确实显示 00:15 / 09:50、视频标题及播放器控件，说明起播参数与嵌入加载有效。

网页父页面访问跨源 iframe 文档抛出 `SecurityError`；观察期间未收到进度消息，官方文档也未给出已验证的持续进度协议。这不能证明所有方案不可能，但不足以通过自动定位发布门槛。浏览器测试工具读取子 frame 是测试能力，不是鱼趣网页可使用的接口。

鸿蒙系统的 [WebviewController.runJavaScript](https://developer.huawei.com/consumer/en/doc/harmonyos-references/arkts-apis-webview-webviewcontroller/)提供当前 Web 页面脚本执行能力。后续已在实际鸿蒙模拟器独立探针中验证：官方移动播放器可加载，标准 video 位置可持续读取，30 秒跳转可确认，系统整页暂停／停止可生效，见[鸿蒙补验](harmony-knowledge-followup.md)。分 P 身份、完整新鲜度约束、所有权与生命周期仍未通过，不由单视频成功放行。

两端视频均保持未发布；不加入手动定位降级版、私有全局、猜测消息协议或扩展／代理方案。以后需逐端满足：位置新鲜度及误差各不超过两秒，暂停／seek／切 P 后旧状态作废，回听定位可确认，失去所有权停止播放，鸿蒙另验真机生命周期。
