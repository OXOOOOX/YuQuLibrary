网页刷新后两条记录的 ID、回答和引用不变。鸿蒙覆盖安装修复版并重新启动后，恢复原账号、节目和 2:28 进度，没有自动播放；两条问题和两段完整回答与网页逐项一致。两端均实际展开 S14 引用，显示 1:37–1:45 的相同原文。手机自动化输入工具仅支持 ASCII，因此追问以英文输入、中文回答；不是中文输入法验收。
