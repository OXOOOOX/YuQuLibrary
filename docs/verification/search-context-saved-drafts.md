# 搜索上下文返回与收藏备注草稿验收

日期：2026-11-18。承接[收听与知识整理验收](listening-knowledge.md)和[恢复与生命周期补验](replay-recovery-video-lifecycle.md)。本轮完善网页与鸿蒙的文稿搜索阅读，以及网页收藏备注编辑；没有修改服务端契约、数据库迁移或生产服务。

## 行为变化

- 两端进入搜索命中的上下文时，保留原搜索词、已经加载的结果、冻结的搜索范围与下一页游标。上下文标出命中句并自动定位；返回搜索结果后恢复原阅读位置，无需重新搜索。
- 鸿蒙“更多搜索结果”改为累积追加；输入框修改但尚未提交时，下一页继续使用原查询。新搜索、切换资料和退出会退役旧请求及待执行定位。
- 上下文读取当前文稿，搜索结果与已选原文保持各自快照。命中句不会因定位而自动勾选；当前文稿已找不到原片段时明确提示。阅读与搜索不接管播放，也不改原问题或收藏来源。
- 网页备注草稿由收藏面板持有。自动刷新挤出条目、翻页或切换筛选后，仍可在独立编辑区继续保存；一次保留一条草稿，编辑另一条时提示先保存或取消。
- 保存请求不随翻页取消；失败保留输入并可重试。成功后立即更新当前列表，同时阻止较早的列表响应覆盖结果。首次读取失败提供重试入口；空的后续页可以返回上一页。

草稿保存在当前页面状态中，不承诺整页刷新、关闭浏览器或退出账号后恢复。

## 实际鸿蒙验证

当前 Debug HAP 经 Hvigor 编译、HDC 安装，在 YuQuPhone 模拟器中实际操作，使用同一独立测试服务。

- 从 20 条追加到 40 条，进入第二页第 28 条：搜索列表切为上下文，命中句可见、高亮且未选中；等待轮询后仍停留原处。
- 返回保留全部 40 条，原点击结果仍在可见范围；继续加载到 48 条，再次进入同一命中句并返回成功。
- 操作前后服务端播放位置保持 `21,398 ms`、代次保持 `21`，没有触发播放接管。
- 实际 UI 树与截图已经核对。自动滚动使用窗口坐标与 Scroller 的 VP 偏移换算，仅在本次导航执行一次；结果列表恢复后才还原搜索滚动位置。

这些证据不替代手机真机、不同字体缩放、软键盘遮挡及长时间运行验证。
