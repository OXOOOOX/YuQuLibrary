# 第一阶段验证记录

日期：2026-11-16。范围：首轮工程搭建、受控音频播放和开发事件传输。**后续更新：DevEco 已安装，鸿蒙实际编译已通过，详见[鸿蒙编译与模拟器记录](harmony-build-emulator.md)。** 下文保留首轮验证时的环境与边界，不能将当时缺少 SDK 的状态视为当前状态。第一阶段仍待设备运行验收。

## 已建立的工程

- `apps/web`：Next.js 网页，标题、播放进度、播放控制和对话占位；对话入口明确禁用。
- `apps/harmony`：ArkTS/ArkUI 原生工程，AVPlayer、AVSession、音频后台任务、应用生命周期及诊断页面。
- `packages/contracts`、`packages/domain`：播放基础类型、测试事件与增量 SSE 解析器；尚非完整同步协议。
- `workers/ingestion`、`workers/codex-bridge`：职责与目录占位，尚未启动任务进程。
- `db/migrations`：独立命名空间初始迁移；迁移执行器、环境示例与本地说明已建立。
- 两端使用同一生成脚本产生 120 秒、16 kHz、单声道 PCM WAV。文件不提交，运行开发或构建命令会生成。
