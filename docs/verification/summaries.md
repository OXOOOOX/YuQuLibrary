# 分段与整期总结本地验收

日期：2026-11-18。对应 R18／A17、计划 P3。代码、独立测试数据库、真实模型、网页与鸿蒙的证据分别记录；本轮未部署生产、重启共享 Bridge／ASR、云签名或上传。

本文保留首版验收快照。后续同日已补约 10 分钟分段、逐点证据约束、三份真实文稿及两端有音频回听，当前代码、产物和未决内容质量见[真实内容复验](summary-quality.md)。下文“有音频回听未单独复验”只对应首轮历史范围。

## 实现范围

- 只对完整文稿主动生成，按原句分批总结后逐级汇总；不要求先生成章节，不把部分 ASR 当成完整节目。
- 原文全部分配，每批最多 600 句／24,000 字符；最大 128 批、3 级归并、147 个任务。完整源上限 48,000 句／2,000,000 字符，超限拒绝，不截断。
- 每点绑定生成时的原文、时间和来源顺序，模型只选择局部编号；父级要点递归展开到原句，最多 16 条。时间允许重叠或零时长，不补造可播放区间。
- 已完成分段先可读，整期结果只在全部任务完成后出现。取消、失败、租约过期都保留完成部分，重试只续做剩余任务。归档保留阅读，完整删除使任务失效。
- 两端按需展开、每页 8 段、逐点查看冻结依据；阅读不接管播放，回听须显式操作。未增加跨节目、导出或 Canvas 对接。

## 自动化与真实模型

最终 `npm run check` 通过配置、两套类型检查、177 项测试及 Next 生产构建；68 个数据库用例在常规测试中跳过后已单独全部通过。Bridge `npm run check` 150 项通过。常规检查不包含 ArkTS，实际 Debug HAP 与 Release APP 构建另行通过，保留既有媒体 API 兼容警告和未签名提示。

`tests/summaries.test.mjs` 5 项验证原文完整分配、600 句／字符双重预算、65 批的三级归并、16 条证据最大路径、精确原文与顺序、零时长和重叠、无效字段／编号和重复要点拒绝。

`tests/summaries.integration.test.mjs` 6 项在独立 `_test` 数据库验证权限、幂等、完整文稿门槛、能力协商、并发领取、旧租约、完成重发、失败／停止续做、输入冻结、多级引用、9 段分页、归档及删除级联、配额和耗尽租约重试。完整数据库套件 68 项通过。所有重建仅针对测试 schema，没有访问生产数据库。

真实模型使用 **720 段／57,872 字符的受控文字**，时间轴设为 60 分钟，无对应音频，不能据此宣称一小时自然播客质量通过。复核修复了 Bridge 默认纯文本与总结 JSON 指令的冲突，新增专用 summaries 模式，输出校验与 domain 对齐。最终模式下重新运行 3 个叶任务和 1 个整期任务全部成功；第一个完成后执行停止／继续，后续从第二段接上，保留第一段。每个输出要点的所有引用均通过 API 取回，与最初 720 段的原文、起止时间逐条比对一致。最终证据为 `real-summary-final-results.json`；初轮结果另存，不混用。

人工核对最终六点：设备预算八万元是上限、交通费用未知；采购仍需预算批准；六月正式上线草案被后续“六月内部试点、九月上线且验收通过”替代；仅限离线沙盒且全国推广未批准；验收同时要求连续七天无中断和日志完整；日志在服务器确认前不能删除。最终要点保留这些条件，没有把未知交通费用相加或把草案当成正式承诺。重复素材被整合为六点；这只证明该受控样本，不建立自然内容遗漏率或幻觉率指标。

## 客户端验证

网页实际 Chromium 桌面及 390px 宽度通过：真实模型概览和三分段、冻结依据展开／收起、归档禁播、9 段按 8+1 分页、首次生成、发送失败复用 requestId、停止／继续、未完成不显示概览、关闭或切到对话停止轮询。操作前后播放代次、媒体和位置相同；无页面异常或 Next 错误遮罩。Browser 插件未提供，使用已安装 Playwright。额外回归在真实浏览器中注入受控响应与 visibilitychange：恢复可见后持续轮询、任务状态变化不中断依据、收起后可重试、切资料的旧依据不污染新页，四项通过；这是合成可见性事件，不等于系统后台实测。结果见 `web-lifecycle-results.json`。

鸿蒙新增 10 个行为场景覆盖总结独立状态、分页、依据、迟到响应、丢响应重试和归档回听；包括切换要点等待时清除旧证据，以及生成与旧轮询并发后不会卡住 busy。实际 ArkTS 构建曾发现 Builder 内局部变量语法错误，已提取 Builder 和辅助方法修复；同时补齐首次生成按钮和整期概览的依据入口。

最终 Debug HAP 安装至 HarmonyOS 模拟器并用本地测试邮箱登录：真实模型整期概览与 3 分段可读，概览依据展开能看到第 1、2 和 720 条原文及真实冻结时间；归档回听按钮不改变播放。9 段目录翻到第 9 段并返回、首次生成、停止／继续、未完成不展示概览均通过；全部操作前后播放代次、媒体与位置相同。截图已人工查看，完整记录为 `native-results.json` 与 `native-*.md`。有音频时的 P3 按钮实际起播尚未单独复验，复用既有片段回听链路；本轮没有把归档禁播验证当成实际音频回听验证。
