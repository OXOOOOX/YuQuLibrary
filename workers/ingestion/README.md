# 导入工作进程

当前实现公开音频的持久下载、格式与时长检查、私有存储，以及任务失败后的显式重试。RSS/Atom 解析在网页 API 内有界执行，用户选择单集后建立音频下载任务。本进程尚未实现 B 站下载、字幕、ASR 或 AI。

## 启动

在仓库根目录配置现有 `.env` 中的独立 `DATABASE_URL` 及绝对 `MEDIA_STORAGE_DIR`，先执行迁移，再运行：

```powershell
npm run db:migrate
npm run worker:ingestion
# 单次尝试领取并处理一项任务后退出：
npm run worker:ingestion -- --once
```

网页 API 与 Worker 使用同一数据库、同一个私有媒体目录。目录应位于 `public` 和受版本控制源码之外，例如 `C:/Users/your-name/yuqu-local/media`。当前只提供本机文件存储；云对象存储、跨主机共享和长期清理策略尚未接入。不要将该目录直接暴露为静态网站。

Worker 不随网页请求自动启动；未运行时任务保留为排队状态。当前单进程逐项处理，无任务时约每 2 秒检查一次。接收到退出信号后结束当前轮，再释放数据库连接。

## 任务与恢复

- 任务状态为 `queued`、`downloading`、`ready`、`failed`。`ready` 只表示音频已可播放，不能表示文稿或转写完成。
- 通过短事务和 `FOR UPDATE SKIP LOCKED` 领取任务；文件下载在事务外进行。
- 每次领取生成独立租约 ID，租约 90 秒，每 15 秒续租。续租、完成和失败写入都检查当前租约及有效期，旧执行不得覆盖新结果。
- 每项最多 3 次尝试，包含首次领取。普通网络或解析失败后需用户点击“重试”；进程中断后的过期任务可以重新领取，仍计入上限。
- 同一次尝试内，传输中断可最多进行 3 轮请求，始终共用 5 分钟期限。仅已收部分正文、总长已知、强 ETag 不变、最终 URL 一致时才续传；要求 HTTP 206、精确 Content-Range 和尾部长度。返回 200/416、弱 ETag 或媒体版本变化时停止，不拼接不同文件。每轮仍重新校验公网地址和至多 5 次跳转。
- 同一用户的规范化来源 URL 去重复用；不同用户分别建立任务和媒体归属。每用户最多 50 条导入记录，排队与下载中合计最多 5 项；暂不提供删除和配额回收。
- 临时文件按任务和租约命名。完整下载、元数据检查与文件落盘后，事务写入媒体记录并标记就绪。若提交结果不确定，保留可能已经被引用的文件，避免错误删除；孤立文件的自动清理尚未实现。

## 下载与媒体边界

| 项目 | 限制 |
| --- | --- |
| 协议 | 标准端口 HTTP/HTTPS，拒绝 URL 内的账号密码 |
| 格式 | 可识别时长的 MP3、M4A、AAC、WAV；本轮公开下载实测为 MP3 |
| 大小 | 100 MiB，检查响应声明与实际接收字节 |
| 时长 | 4 小时 |
| 下载期限 | 一次最多 5 分钟，另有远端空闲超时 |
| 连接与响应 | DNS/建连/响应头每轮合计 30 秒；已连接后 15 秒空闲超时 |
| RSS/Atom 预览 | 2 MiB、20 秒；扫描前 300 条、最多返回 100 个有效音频地址；每用户至少间隔 5 秒 |

每次解析和重定向都拒绝非公网地址，连接固定到已批准 IP，HTTPS 保留证书验证；下载不携带用户登录 Cookie 或令牌。RSS 禁止 DTD/实体声明，并正确处理内置/数字实体及最终重定向 URL 的相对音频地址。

部分本机代理会把公网域名解析为保留 fake-IP。只有需要该适配时，显式设置 `YUQU_PUBLIC_DNS=1`：通过固定公共 DNS 的 TLS 端点获取地址，随后继续公网校验和固定连接。默认关闭；该配置不会允许私网、环回或保留地址。

音频由网页的 `/api/media/[id]` 经账号和媒体归属验证后提供，支持 GET、HEAD 和单段 Range；存储路径不返回客户端。

## 当前验证边界

两条公开 MP3 已实际下载入库并在网页播放；鸿蒙模拟器已通过网络 MP3 从 185 秒续播、30 秒灭屏持续上报、网页切集后暂停，以及逐集位置恢复。手机界面另行提交的短 MP3 任务首次下载即就绪。真实 RSS 所选音频前两次失败，第三次下载完整并在两端播放通过。追加的真实源中断测试使用 HTTP 206 续传，完整文件 SHA-256 与 Worker 下载结果一致。网络并非每次都成功，原先两次失败的具体原因没有被倒推认定。

日志区分存储、下载、解析和发布阶段，并保留字节数、耗时、请求次数及受限错误码。总期限、租约失效、源站传输中断、DNS 与证书错误均有固定文案；不记录原始错误消息、完整 URL 或凭据。进程强杀后的临时文件仍不跨租约续传，自动孤立文件清理尚未提供。

数据库任务、租约、用户隔离、重试上限和媒体 Range 等由独立 PostgreSQL 集成测试覆盖。详见[本地运行](../../docs/local-development.md)与[导入验证记录](../../docs/verification/library-imports.md)。服务未部署到公网，真机、B 站、ASR 和 AI 尚未完成。
